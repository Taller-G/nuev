# dasd

## Description
This project is a production-ready boilerplate that implements Clean Architecture using HTML, CSS, and JavaScript.

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Start the application using `npm start`.

## Clean Architecture Layers
- **Domain**: Contains business rules and logic.
- **Application**: Orchestrates domain objects to fulfill use cases.
- **Infrastructure**: Implements the interfaces defined in domain/application.
- **Interfaces**: Entry points into the application.
